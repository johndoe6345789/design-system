# design-system

Split out of `next_extra_primary/shared` and `next_extra_primary/services/design-system` as part of the [reposplit](https://github.com/johndoe6345789/reposplit) effort.

Not the same thing as [RevolutionaryWayToServeUpReactApps](https://github.com/johndoe6345789/RevolutionaryWayToServeUpReactApps) (a codegen/project-generation tool) - that was an earlier wrong name match. This repo holds the shared React UI kit (components, hooks, icons, interfaces, redux, schemas, scss, storybook, theme, constants) used by `next_extra_primary`'s and `businessplanner`'s `frontend/` apps.
